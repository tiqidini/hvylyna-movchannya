# Хвилина Мовчання (Minute of Silence)

Веб-додаток для проведення загальнонаціональної хвилини мовчання в Україні, яка відбувається щодня о 09:00.

## Огляд проекту

Цей проект є інтерактивним таймером, який автоматично активує аудіосупровід (голос диктора, метроном або музику) рівно о 09:00 за київським часом.

### Основні технології:
- **Next.js 15+ (App Router)** — основний фреймворк.
- **React 19** — інтерфейсна бібліотека.
- **Tailwind CSS 4** — стилізація (використовує нову архітектуру v4).
- **TypeScript** — типізація.
- **Web Audio API** (через HTML5 Audio) — для відтворення звуку.

### Архітектура:
- `src/app/page.tsx` — головна сторінка.
- `src/components/Player.tsx` — основний UI-компонент плеєра.
- `src/lib/audio-engine.ts` — кастомний хук `useAudioEngine`, який містить всю логіку зворотного відліку та керування аудіо-потоками.
- `public/audio/` — статичні аудіо-файли (.mp3).

## Команди для розробки та збірки

### Встановлення залежностей:
```bash
npm install
```

### Запуск у режимі розробки:
```bash
npm run dev
```

### Збірка проекту:
```bash
npm run build
```
*Примітка: проект налаштований для статичного експорту (Static Site Generation), результати збірки знаходяться в папці `out/`.*

### Робота з аудіо (Python):
Для завантаження офіційного голосу диктора з "Українського радіо":
```bash
python download_real_announcer.py
```

## Конвенції розробки

1.  **Стилізація**: Використовуйте класи Tailwind CSS 4. Проект має преміальний "темний" дизайн (Black/Dark mode) з акцентом на типографіку та градієнти.
2.  **Аудіо-логіка**: Вся бізнес-логіка, пов'язана з часом та звуком, повинна залишатися в `src/lib/audio-engine.ts`. Не змішуйте її з UI-компонентами.
3.  **Локалізація**: Інтерфейс проекту ведеться українською мовою.
4.  **Статичні ресурси**: При додаванні нових аудіо-файлів використовуйте функцію `getAudioPath` з `audio-engine.ts`, щоб забезпечити коректну роботу шляхів при деплої на GitHub Pages.
5.  **Персистентність**: Налаштування користувача (вибір аудіо-режиму) зберігаються в `localStorage` під ключем `hvylyna_audio_mode`.

## Тестування

Для перевірки роботи звуку та візуальних ефектів використовуйте кнопку **"Запустити тест"** в інтерфейсі. Вона імітує настання 09:00 та запускає обраний аудіо-супровід.
